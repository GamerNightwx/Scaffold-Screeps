# Screeps Bot

Projeto de exemplo para bot de Screeps com build em `esbuild`.

## Instalação

```bash
npm install
```

## Build

```bash
npm run build
```

## Verificação

```bash
npm run check
```

## Estrutura

- `src/` código-fonte
- `dist/` saída do build
- `docs/` documentação do projeto
